# security policy

## supported versions

security fixes are released for the current major version only.

| version | supported |
| --- | --- |
| 2.x | yes |
| 1.x | no |

## reporting a vulnerability

do not open a public issue for a suspected vulnerability. use
[github's private vulnerability report](https://github.com/jtayped/mercapy/security/advisories/new)
and include:

- the affected mercapy version;
- a minimal reproduction or proof of concept;
- the expected impact; and
- any suggested fix or mitigation.

remove credentials, personal data, and unrelated live api responses before
submitting a report. you can expect an initial response within seven days.

## scope

reports about mercapy's source code, package, workflows, and release process are
in scope. mercadona and algolia operate the upstream services and must receive
reports about their own systems through their security channels.
